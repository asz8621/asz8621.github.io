使用 Vue slot 讓組件更加靈活

發表於 2024-10-29 分類於 Vue
本文介紹四種基本插槽的使用方式，包括預設插槽、具名插槽、作用域插槽和動態插槽，幫助開發者設計更具靈活性的 Vue 組件。

前言

Vue.js 提供了強大的插槽（slot）功能，讓父組件能靈活地將內容傳遞給子組件。本文將介紹四種插槽的基本用法。

插槽（Slots）

插槽是 Vue 中最基本的使用方式，允許父組件在子組件中插入特定內容，如果插槽的內容只有一個則不用填寫 slot 名稱。

父組件：

  • Options API
  • Composition API
  • script setup

子組件：

  • Options API
  • Composition API
  • script setup

具名插槽（Named slots）

具名插槽允許子組件定義多個插槽並指定名稱，這樣可以增強父組件在使用時的靈活性。

在 Vue 中，v-slot 可以縮寫為 #，後面接插槽的名稱（即 name 屬性），例如：#header。

父組件：

  • Options API
  • Composition API
  • script setup

子組件：

  • Options API
  • Composition API
  • script setup

作用域插槽（Scoped Slots）

作用域插槽允許父組件從子組件獲取數據，並將其傳遞到插槽中，實現根據子組件狀態或屬性動態渲染內容。

父組件：

  • Options API
  • Composition API
  • script setup

子組件：

  • Options API
  • Composition API
  • script setup

動態插槽（Dynamic Slots）

動態插槽允許根據條件渲染不同的插槽，適用於需要在同一組件中根據狀態顯示不同內容的情況。

父組件：

  • Options API
  • Composition API
  • script setup

子組件：

  • Options API
  • Composition API
  • script setup

總結

透過上述範例，我們可以看到 Vue 的插槽功能如何有效提升組件的靈活性。無論是選擇哪個插槽，都能讓開發者在組件之間輕鬆傳遞內容，實現更複雜的 UI 結構。
